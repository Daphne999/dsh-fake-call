# dsh-fake-call

> 一页"有人打电话给你"的通话界面，对面是 DSH 里的 AI —— 声音在本机合成，零 API key。

打开 `/fake-call` 就是一个来电：头像在跳、有接听/挂断。点接听，对面**真的会说话**（Windows 自带的语音合成，离线、不花钱），你打字回它，它用一两句口语接你的话。

## 它和"AI 打电话"的区别

市面上那些"AI 主动打电话"要么走 Twilio / WhatsApp Business（要企业资质、按分钟计费），要么其实只是把来电界面做出来的演示。这个插件把"演示"这部分做扎实：

| | 真不真 |
|---|---|
| 听见声音 | ✅ 本机 SAPI 合成，真的出声 |
| 对话 | ✅ 走 DSH 自己的会话，有上下文 |
| 打电话到你手机 | ❌ 没有运营商通道，做不到 |
| 录音/上传音频 | ❌ 不录音、不上传 |

## 装

```bash
dsh plugin --profile web add dsh-fake-call
```

> 目前只支持 Windows（依赖系统自带的 SAPI 语音合成）。

## 用

1. 浏览器打开 `http://127.0.0.1:61310/fake-call`
2. 点「接听」
3. 打字说话（未来会接语音识别）

也可以让 AI 主动打过来 —— 它会调用 `fake_call` 工具让页面进入振铃状态：

```
fake_call { "caller": "小鱼" }
```

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `caller` | `小鱼` | 来电显示的名字 |
| `voice` | 空 | 指定音色，空则自动挑系统里的中文音色 |
| `cwd` | 宿主 cwd | 通话会话的工作目录 |
| `replyTimeoutMs` | 120000 | 一轮回复上限 |
| `maxRounds` | 40 | 一通电话最多几轮 |

## 实现要点

- **TTS 缓存**：同一句话只合成一次（`%TEMP%\dsh-fake-call\<md5>.wav`），重复句子不再等 1 秒
- **文本注入防护**：拼进 PowerShell 的文本会做单引号转义，避免引号逃逸
- **只取一句话**：模型爱写长段落，`oneLine()` 会剥掉代码块/列表/链接并截断，保证像打电话
- **业务内核与宿主解耦**：路由逻辑在 `lib/call.js`，不 import 任何 DSH 内部模块，测试里注入假 agents 就能跑

## 已知限制

- 只有 Windows 能用（macOS/Linux 需要换 TTS 后端）
- 用户侧输入目前是**打字**；语音识别（ASR）还没接
- 音色取决于系统装了什么（中文一般是 Microsoft Huihui）
